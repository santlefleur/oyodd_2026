# oyodd_2026

Repositorio de la materia "Estructura y Organización de Datos", semestre 2026B.

## Descripción

Repositorio para el curso de Estructura y Organización de Datos. Contiene apuntes, prácticas, ejercicios y recursos relacionados con tipos de datos abstractos, estructuras de datos y métodos de ordenamiento y búsqueda.

## Competencias a desarrollar

- Identificar, seleccionar y aplicar eficientemente tipos de datos abstractos.
- Aplicar métodos de ordenamiento y búsqueda para la optimización del rendimiento de soluciones a problemas del mundo real.
- Analizar la complejidad temporal y espacial de algoritmos y estructuras de datos.

## Contenido

- Unidad 1: Fundamentos de estructuras de datos
- Unidad 2: Estructuras lineales
- Unidad 3: Estructuras no lineales
- Unidad 4: Métodos de ordenamiento y búsqueda
